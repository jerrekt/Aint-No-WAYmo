# Ain’t No Waymo visual design — V1.001 candidate

- Design intent: a restrained, original student-project interface influenced by autonomous-mobility colors, **not** a reproduction of Waymo's distinctive website or logo.
- Palette: off-white `#f6f8fc`, white `#fff`, ink `#172843`, blue `#3564d8`, green `#169c78`, neutral border `#dce3ed`. These are project choices, not official color specifications.
- Typography: Arial/Helvetica system stack; strong type hierarchy, simple rectangles, no glows or gradient background.
- Top left: a temporary original direction-arrow placeholder, project title **Ain’t No Waymo**, subtitle **Mini-Waymo · SJSU SME**. Replace placeholder later with a unique student-created logo; do not reproduce Waymo's logo.
- Retain disclaimer: independent student project, not Waymo or Opera affiliation.
- Design edits are part of the **pending V1.001 draft**, not an additional official merge; no V1.002 until V1.001 is merged.
- Main entry: `Mini_Waymo_V12_Demo.html` (historic filename for compatibility); standalone About: `Mini_Waymo_V12_About.html`.
- The CSS override is embedded within each HTML file for offline use; also maintained as `assets/visual-theme-v1.001.css` for handoff/reference.
