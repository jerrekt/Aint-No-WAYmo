# V1.006 selected diecast visual reference

The website header no longer shows the generic fictional mini-car SVG. It shows a **diecast-style render** of the selected white Waymo Jaguar I-PACE miniature, with rooftop sensors and a display base. This is an illustrative rendering, not a photograph of the actual physical model or proof of fit.

Asset: `assets/mini-waymo-diecast-reference.jpg`. It is inlined in the offline single-file `Mini_Waymo_V12_Demo.html`, so the demo opens without hosting assets. The source preserves a replaceable image file for the team's eventual real product photographs.

Important: This change does not alter or relax the requirement to fit the actual XIAO ESP32-S3, motors and battery inside the measured diecast shell. The optional FPV trailer remains out of scope for the three-week MVP.

This vehicle reference update is batched with the estimated survey map update in the **unmerged V1.006 draft**; do not count two updates or increment the version again until the next accepted merge.
