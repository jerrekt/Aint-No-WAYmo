# V1.005 draft — Waymo-app-inspired visual refresh

The owner provided screenshots of a dark-navy Waymo app. The design captures its broad principles (dark layered navy, generous negative space, large soft tiles, centered vehicle art, and floating bottom nav) without copying the app UI code, photography, trademarks, or logo.

- Official title: **Ain't No Waymo**; subtitle **Mini-Waymo · SJSU SME**.
- Original schematic vehicle illustration is expressly labeled not-to-scale.
- Bottom dock: Live Map, Build (opens and scrolls the task board), About, Theme.
- Existing Ride Blue, Midnight, and Mint Circuit previews remain accessible via **Appearance**, while **Waymo App** is the new default.
- Task claim API requires the server-side private password and persistent Kratos backend. No password is embedded in HTML or committed to Git. A shared password is not individual identity verification.
- Only layout and CSS change; physical robot still not verified and map is still an illustrative simulation.
- Baseline V1.000 and previously numbered V1.001–V1.004 are historical/draft development stages; this is proposed **V1.005**; coordinate version bumps before merging PRs.
